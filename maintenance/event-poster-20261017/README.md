# Афиша события — локальный вариант 17.10.2026

17.10.2026 после совместных правок пользователь поручил один общий коммит афиши и публичного гест-листа и публикацию на gomeet-organizers.ru. Этот исходник и intermediate bundle сохраняют начальную афишу; финальный пакет строится в [guest-list-20261017](../guest-list-20261017/README.md), включая перекрывающиеся аватары и открытый Going без «Написать». Прежние NOT RUN ниже относятся к первоначальной локальной проверке; итог выпуска отдельно в design/guest-list-concept-20261017/r5/PUBLICATION.json. Дополнительные изменения не включаются.

UI-EVENT-POSTER-20261017. Пользователь сохраняет существующую геометрию: афиша на первом экране, название внизу, дата/время; прочие сведения после прокрутки. Поручены перенос «Кто идёт» под первую черту, перед организатором/местом, новый вид этой ссылки и удаление тематических категорий. Компактные «Иду»/лайк предложены пользователем и подготовлены для просмотра. Сам экран Going и owner-only управление GuestList не переделываются.

## Реализация и критерии

`event-detail.js` — читаемый исходник exact factory1539 с адресными UI-правками. `poster-like.tsx` — локальный компактный вариант существующего сердечка с focus/hover/selected/disabled состояниями. `build.cjs` компилирует его теми же установленными Babel-зависимостями и заменяет только1539; прочие factories и dependency map сохраняются. Исходный bundle остаётся на диске.

Проверки: исходный hero/date и расчёт высоты сохраняются; после прокрутки черта→Кто идёт→организатор/место→описание; существующие данные, условие totalGoing>0 и маршрут Going остаются; главная кнопка сохраняет ticket/purchase и loading/disabled состояния; кнопки компактны, но минимум44px, фокус видим; тематический category не выводится, ageLimit сохраняется.360/390px без horizontal overflow. До просмотра пользователя — только локально.
