## Предложение

Одна афиша на экран и вертикальное перелистывание, прежняя нижняя навигация. По D-051 заголовок «Лента» и счётчик удалены. По последующему D-052 отметка «сейчас» тоже удалена; верхних интерфейсных подписей нет. По D-050 внизу восстановлены прежние крупное название34/40, организатор/аватар32, отдельная строка «О событии» на месте «ещё». Дата, время и место не выводятся поверх постера; доступны в прежнем листе описания. Новый ряд «Иду» с ценой48px и сердце48px сохранён из r1 без изменений функций/стилей, что сверено по AST. Категорий нет. R1 и его исходники/проверки сохранены в design/feed-concept-20261018/r1 и LOCAL-SPEC-r1.md.

useFeed/useEvent/useGoingMap/useGoing/useSaved остаются источниками чтения. Обычный Back сохраняет событие/позицию. Сердце в preview меняет только React state; CTA билета даёт внешний notice, не открывая checkout. Прежний Purchase callback сохранён как reference будущего внедрения. Реальные избранное/подписки/сообщения/жалобы/блокировка/покупка не выполняются. Лист описания — часть Feed; афиша и профиль организатора используют уже опубликованные экраны.

Появление180ms использует исходный useReduceMotion; при reduced motion значение устанавливается сразу. Новых ассетов/генерации не было. Первый исходный постер содержит собственную апрельскую дату, отличную от октябрьских данных демособытия; она не исправлялась вымышленным изображением, интерфейсная дата взята из event.
