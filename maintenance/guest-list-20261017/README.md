## Требования и критерии

- Афиша: прежняя рамка/место/геометрия и44px кнопки сохранены; до4 доступных аватаров перекрываются на12px, кольца отделяют их. Число без повторения «кто идёт / человек идут». Без доступных фото нет выдуманных портретов; Avatar использует инициалы при отсутствии фото.
- Going: контекст события, общий счётчик, компактные строки доступных профилей с аватаром/именем/username и прежней кнопкой сообщения; оставшиеся участники одной информационной карточкой. Нет стены из24 пустых кружков. Количество доступных preview профилей не выдаётся за полный список.
- Loading/error/retry/empty/unavailable различены. Нет ложного обещания видимости после покупки. Переход к сообщениям и query key/function/enabled сохранены; отправка сообщений не тестируется.
-360/390px без document overflow, кнопки минимум44px, keyboard focus и Back проверены. Заголовок/дата и hero subtree афиши сохранены. Предыдущая r1 сборка сохранена на диске.

При проверке прямого входа обнаружено, что прежний Going не имел явной path-привязки и после reload открывал профиль. Добавлена только Going:"Going" в1033 к существующему экрану. Итог меняет1033/1539/1603, остальные1637 factories и dependency maps сохранены.

## Уточнение r2

Общее число не равно числу доступных профилей. В основном demo теперь94 участника:4 иллюстрированных профиля из подписок и90 остальных общим числом. Реальные данные candidate не менялись. Первоначальные4 означали размер набора для демонстрации, что было неочевидно; подпись режима уточнена.
