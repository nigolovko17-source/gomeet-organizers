# «Я» организатора — локальный r3

20.10.2026. Уточнение пользователя: рассмотрение первоначальной заявки существует только в пользовательском режиме, в настройках. Ограниченная организаторская «Я» появляется после одобрения. Отметка «Заявка одобрена» постоянна; проверка дополнительных данных не означает повторного рассмотрения первоначальной заявки.

## Этапы

1. Подтверждения.
2. Проверка дополнительных данных, включая ожидание и уточнения.
3. Документы.
4. Реквизиты — отдельный последний этап.

После всех четырёх этапов возможна задержка обновления готовности кабинета. Загрузка и ошибка не отменяют первоначальное одобрение. Все восемь состояний ограниченной «Я» сохраняют аватар/имя/@ник/город и только подключение, без счётчиков/подписчиков/событий/финансов. Страницы подтверждения, акцепт документов и дальнейшие операции исключены из задачи: CTA только сообщает о будущем переходе во внешней панели просмотра.

До одобрения сценарий guest-pending показывает исходный пользовательский профиль и навигацию. В настройках — недоступная для нажатия строка «Заявка на рассмотрении», без перехода в организаторский режим. Переключение демонстрационных состояний наружной панелью не меняет реальные роли или данные аккаунта.

## Сохранённые решения

Подключённый профиль остаётся без подключения/трофеев/значков/промокодов; содержит прежнюю идентичность, счётчики, события и «Расчёты и выплаты» → собственная OrgSummary. Staff Payouts недоступен через этот вход. Настройки: гостевой режим → Профиль → Организатор → Сервис → выход. Почта/приватность в Профиле; билеты/заблокированные/расчёты удалены из настроек.
