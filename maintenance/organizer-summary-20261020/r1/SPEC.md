## Спроектировано и реализовано

Без верхней строки режима и логотипа. Компактный выбор события/периода. Три вкладки. Крупная выручка, билеты, заказы. Динамика: столбцы (по умолчанию), линия, заливка — переключаются на одной серии; дата выбирается, значения доступны таблицей, выручка/билеты/дни/месяцы/часы. Горизонтальные диаграммы по событиям с переходом к событию, явка платных/бесплатных, кольцо явки, воронка просмотра/покупки. Аудитория: новые/вернувшиеся, покупатели с пагинацией, удержание. Продвижение: каналы, позиции в ленте, рекомендации, демонстрационные промокоды с event scope. Шесть внешних состояний: обычное, нет событий, нет продаж, загрузка, ошибка с повтором, нет tracking.

Это отдельный дизайн-концепт с условными данными, не замена runtime. Существующие финансовые маршруты и соседние вкладки обозначены handoff, их экраны не переделаны. Промокод формы сокращены для макета: исходные fixed/fee-payer/expiry/лимиты/билет/RPC не портированы. Полная функциональная интеграция — отдельный этап; не выдавать этот макет за parity production. Нет реальных покупателей/операций. CSP connect-src none, значения в RAM. .ru/.su не менялись. Исходные функции .ru остаются прежними.
