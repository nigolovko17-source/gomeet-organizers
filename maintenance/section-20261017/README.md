## Предложение

Убрать повторную крупную обложку первого события. В шапке — название подборки, прежнее описание и фактическое число событий. Карточки с постером96×128, датой, названием, местом и прежней ценой; сердце44×44 справа внизу. Отступы20, межкарточный интервал12. Фирменные Murs/Onest, чёрная основа и существующие афиши сохранены. Категории и новые действия не добавляются.

Данные и порядок событий берутся из прежнего `useHomeSections`. Состояния ready/empty/loading/error доступны в локальной оболочке; «Повторить» выводит из демонстрационной ошибки. Навигация в существующую афишу и обратно сохранена. В Section preview сердца меняют только React state, без `useSaved.toggle()`; в выпуске действует исходная функция избранного. Переходы за пределами Section используют прежние экраны. Проверка не должна запускать реальные платежи, жалобы, сообщения или подписки.
